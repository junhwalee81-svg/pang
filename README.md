# 팡팡 골프

세 번의 터치로 치는 캐주얼 3D 골프. `index.html`을 더블클릭하면 설치 없이 바로 실행됩니다.

## 조작
| 입력 | 동작 |
|---|---|
| 화면·게이지 터치 / Space | 시작 → 파워 고정 → 임팩트 |
| 타점 공 끌기 / WASD | 스핀·각도(위아래), 휘는 방향(좌우) |
| 화면 좌우로 끌기 / ←→ | 조준 |
| 1~4 | 클럽(1W, 5I, SW, PT) |
| ⛳ 그린 보기 버튼·미니맵 / G | 샷 전에 그린 내려다보기 |
| 퍼팅 | 시작 → 세기 한 번(임팩트 없음) |
| 게이지가 오를 때 긋기·원·점 / 화살표 | 특수샷 커맨드 |

임팩트 마커가 금색 구역에 멈추면 "팡!"이고 비거리가 늘어납니다. 커맨드를 넣고 정확히 맞히면 특수샷이 나갑니다(토마호크 ↑↑, 스파이크 ↓↓, 회오리 ←↑→, 도트 ↑↓↑). 임팩트를 놓치면 타수 없이 다시 칩니다.

## 내용
- 코스 6홀(봄·가을·해안·노을), 바람, 경사, 벙커, 연못
- 캐릭터 6종과 패시브, 장비 5슬롯, 코인 상점(브라우저에 자동 저장)
- 효과음은 전부 코드로 합성
