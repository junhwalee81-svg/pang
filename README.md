# 팡팡 골프

세 번의 터치로 치는 캐주얼 2D 골프. `index.html`을 더블클릭하면 설치 없이 바로 실행됩니다.

## 조작
| 입력 | 동작 |
|---|---|
| 샷 버튼 / Space | 시작 → 파워 고정 → 임팩트 |
| 화면 터치 | 게이지가 움직일 때 파워 고정·임팩트 |
| 1~4 | 클럽(1W, 5I, SW, PT) |
| ↑↓ | 발사각 |
| ←→ | 톱·백스핀 |
| Q / E | 토마호크 / 스파이크(해금 후) |

임팩트 마커가 금색 구역에 멈추면 "팡!"입니다. 같은 홀에서 2회 성공하면 특수샷이 열립니다.

## 내용
- 코스 6홀(봄·가을·해안·노을), 바람, 경사, 벙커, 연못
- 캐릭터 6종과 패시브, 장비 5슬롯, 코인 상점(브라우저에 자동 저장)
- 효과음은 전부 코드로 합성
